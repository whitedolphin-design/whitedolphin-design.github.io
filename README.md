# White Dolphin website

## Upload to GitHub
1. Unzip White-Dolphin-Website.zip on your computer.
2. Open your GitHub repository, then Add file > Upload files.
3. Drag the CONTENTS of the extracted folder into GitHub: index.html, style.css, script.js, assets, and README.md. Keep the assets folder intact. Do not upload the ZIP or an enclosing folder.
4. Click Commit changes.
5. Open Settings > Pages. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
6. Wait for GitHub to publish the site. The Pages settings will show its actual address.

Your index.html must be at the repository root. GitHub Free requires a public repository for Pages.

## Preview on your computer
Open index.html in a browser. Keep the other files and assets folder next to it.
